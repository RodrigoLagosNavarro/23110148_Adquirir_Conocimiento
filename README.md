Chatbot con Adquisición de Conocimiento

Este proyecto implementa un chatbot sencillo en Python que puede aprender nuevas respuestas durante la conversación.

Características:

- Base de conocimiento inicial
- Búsqueda de coincidencias en preguntas
- Aprendizaje interactivo
- Almacenamiento de conocimiento en JSON

Tecnologías utilizadas:

- Python
- JSON
- Visual Studio Code

Funcionamiento:

1. El chatbot busca coincidencias en su base de conocimiento.
2. Si encuentra una respuesta, la devuelve.
3. Si no encuentra coincidencias, solicita al usuario una respuesta.
4. Guarda el nuevo conocimiento para futuras conversaciones.
